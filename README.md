# 🧮 Calculator App

A simple and user-friendly **Calculator Android application** built with **Kotlin and Jetpack Compose**. The app provides basic arithmetic operations through a clean and responsive interface.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear input
* 🔢 Numeric input handling
* ⚠️ Basic input validation
* 📱 Responsive Android UI
* 🎨 Clean and simple interface

## 🛠️ Technologies Used

* **Kotlin**
* **Jetpack Compose**
* **Android Studio**
* **Material Design**

## 📱 App Overview

The Calculator App is designed to perform common arithmetic calculations in a simple and easy-to-use interface.

The project focuses on:

* Building Android UI with Jetpack Compose
* Handling user interactions
* Implementing calculator logic
* Organizing application code cleanly
* Creating a responsive mobile interface

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* Android Studio installed
* Android SDK configured
* Kotlin support enabled
* An Android device or emulator

### Installation

1. Clone the repository:

```bash
git clone https://github.com/areejfatima313/Calculator.git
```

2. Open the project in **Android Studio**.

3. Allow Gradle to sync and download the required dependencies.

4. Connect an Android device or start an emulator.

5. Click **Run** to build and launch the application.
